# Contributing to WebCheck Action

Thank you for considering a contribution to WebCheck Action!

## Getting Started

1. Fork the repository.
2. Clone your fork and create a feature branch.
3. Install dependencies: `npm ci`
4. Make your changes.
5. Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
6. Commit your changes with a message starting with `chore:`.
7. Open a pull request against the `main` branch.

## Development

- This is a TypeScript GitHub Action.
- Source lives in `src/`.
- Tests live in `tests/` and use Vitest.
- The bundled Action entry point is `dist/index.js`, generated by `@vercel/ncc`.
- Lint uses ESLint with `@typescript-eslint`.
- Type checking uses `tsc --noEmit`.

## Pull Request Process

- Ensure all checks pass (`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`).
- Update the README and CHANGELOG if you change behavior or inputs/outputs.
- Keep dependency versions pinned and compatible with the GitHub Actions Node.js runtime.
